## map.md 内容

**Destination**:ESP32-C3 Mini TV 真机运行完整固件:左右滑动三张 Fluent 风卡片(① 翻页时钟+未来24h气温折线+日历节假日倒数;② Linux 电脑 CPU/GPU 监控+一键打开抖音/VSCode/B站;③ 米家灯光拟态开关),下拉控制中心(背光滑条+Wi-Fi 设置),数据与控制统一经 Home Assistant,逐卡真机验收。

**Notes** 要点:
- 本努力**携带实现**(目的地是真机全实现),故 09–12 为执行型 task 工单——这是对 wayfinder 默认"只规划"的显式覆盖。
- 硬件权威事实(来自 `Firmware/docs/hardware/HADRWARE.md`):ESP32-C3-12F 4MB flash(现 sdkconfig 误设 2MB,需改)、无 PSRAM;ST7789 240x320 SPI(SCLK4/MOSI6/DC7/RST8/CS10/BLK5 PWM 背光);CST816D 电容触摸 I2C(SDA2/SCL3/INT0/RST1);BOOT 键 GPIO9;ESP-IDF v6.0.2,必须 esp_lcd+DMA、新版 i2c_master API、board_pins.h、FreeRTOS 任务;RAM 预算 ~300KB。
- 用户已定:后端统一 Home Assistant(从零装);米家经 HA;被监控电脑是 Linux;配网用手机网页(SoftAP 门户);节奏=先骨架后逐卡;米家设备组合=Wi-Fi 直连灯+蓝牙 Mesh 开关+小米中枢网关。
- 各 grilling/task 工单开会时调用 /grilling 与 /domain-modeling。

**Not yet specified**(雾):中文字体子集与 flash 布局细节;OTA 是否纳入;节假日数据若内置年表的更新机制;控制中心是否需要更多二级页(骨架验收时再定)。

**Out of scope**:git/CI 初始化;屏上软键盘配网(已选手机网页);ESP32 充当 BLE 网关直连米家。

各工单 Question 全文:

1. **01 UI 技术栈与视觉系统定案**:LVGL(9.x 经 idf_component.yml)在 ESP-IDF v6.0.2 的版本与已知坑;中文字体方案(子集位图 vs 全量,4MB flash 体积预算);Apple Fluent 卡片风在 240x320 无 PSRAM 的落地规范(圆角/阴影/模糊降级、配色、动效帧率目标)。
2. **02 Home Assistant 安装主机方案**:装在什么硬件(树莓派/NAS Docker/闲置小主机/虚拟机)、哪种形态(HAOS/Container/Core);要求常开、同局域网、能跑米家集成与命令执行、可跑性能采集。
3. **03 米家接入 HA 路径调研**(AFK):官方 Xiaomi Home 集成 vs HACS Xiaomi Miot Auto;对「Wi-Fi 直连灯+蓝牙 Mesh 开关+中枢网关」组合的能力边界、是否本地控制、延迟稳定性;BLE Mesh 是否必须经中枢。
4. **04 ESP32↔HA 对接规范调研**(AFK):长期访问令牌+REST(/api/states、服务调用)vs WebSocket 订阅推送;mDNS 发现;局域网 http vs https 的证书/内存成本;ESP-IDF v6.0.2 可用组件。产出推荐接口契约(轮询周期、订阅、控制调用格式)。
5. **05 骨架里程碑验收标准**:esp_lcd ST7789+DMA 点亮、CST816D 中断驱动与手势、LVGL tick/任务、三卡片滑动壳+指示点、下拉控制中心(背光 PWM 滑条+Wi-Fi 入口)、SoftAP 网页配网、NTP 对时、4MB flash/分区表修正;逐条可勾选验收项与内存基线。
6. **06 卡片1 数据源与呈现**:天气走 HA weather 实体还是 ESP32 直连 open-meteo;气温折线用 LVGL chart 还是自绘;翻页时钟动效;日历节假日倒数数据源(内置年表 vs 在线 API);刷新周期与断网降级。
7. **07 卡片2 方案**:Linux 性能采集(显卡厂商未知:NVIDIA nvidia-smi / AMD sysfs / Intel intel_gpu_top 分支)进 HA 的方式(Glances 集成 vs 自写上报);指标集;一键打开抖音/VSCode/B站用 HA shell_command+SSH 还是电脑侧小代理;鉴权与点击反馈。
8. **08 卡片3 方案**:客厅/房间灯与 Mesh 开关的 HA 实体清单;拟态开关交互规范(按下/加载/失败态);开关→HA 服务调用的延迟处理与状态回读同步,防 UI 与实际灯态漂移。
9. **09 骨架实现与真机验收**:按 05 验收标准实现 ST7789/CST816D/LVGL/滑动壳/控制中心/配网/NTP,勾完全部验收项。
