# 05 骨架里程碑验收标准

Type: grilling
Status: resolved
Blocked by: 01

## Question

先把「能滑、能控、能上网」的骨架在真机验收,再逐卡实现。定下验收标准:

1. **屏幕**:esp_lcd + ST7789 240x320 DMA 点亮,背光 GPIO5 PWM 可调;开机画面。
2. **触摸**:CST816D(I2C,INT/RST)驱动 + 手势(左右滑动、下拉、点击)经 LVGL 输入层工作。
3. **UI 壳**:三张卡片横向滑动 + 页面指示点;下拉控制中心(背光滑条 + Wi-Fi 设置入口 + 网络状态显示);动画流畅度标准(帧率/掉帧容忍)。
4. **配网**:SoftAP 手机网页门户(输 SSID/密码/可选 HA IP),NVS 持久化,重连逻辑;控制中心里显示 IP/信号强度,能重进配网。
5. **系统**:NTP 对时、RTC 保持;4MB flash 分区表修正(现误设 2MB);内存基线(启动后剩余 heap,给卡片们留多少)。
6. **验收方式**:每项给出可勾选的验收标准(可观察/可测量),真机过一遍。

产出:09 的实现验收清单(勾选式)。同时定控制中心是否要更多二级页(雾,在此收敛)。

## Answer

### 结论

骨架里程碑(Skeleton Milestone)的目标是:真机已经具备后续三张卡片可依赖的硬件、UI、配网、时间和后端可用性基础,但**不实现**卡片1/2/3的完整业务数据。工单 09 按本清单实现并逐项验收。

控制中心首版不做更多二级页。它只包含背光 PWM 滑条、Wi-Fi 状态/IP、HA 后端状态和重新配网入口。更多网络详情、实体选择、调试页以后再开工单,不进入骨架。

### 骨架范围边界

骨架必须完成:

- ST7789 显示链路、CST816D 触摸链路、LVGL 8.3.11、三卡片 `lv_tileview` 壳。
- 顶部下拉 Control Center overlay。
- 背光 PWM 调节。
- SoftAP 手机 Provisioning Portal,保存 Wi-Fi 与可选 HA endpoint/token。
- STA 连接、NTP 对时、HA 后端在线/离线探测。
- 4MB flash 配置修正和基础内存/FPS 记录。

骨架不得提前承诺:

- 天气/预报真实数据、节假日倒数完整逻辑(工单 06/10)。
- Linux CPU/GPU 真实监控和打开应用动作(工单 07/11)。
- 米家灯真实控制和实体映射(工单 08/12)。
- HTTPS 证书导入完整体验。骨架允许本地调试 `http://<linux-host-ip>:8123`,但代码结构必须保留后续 HTTPS/CA/NVS encryption 接口。

### 1. 启动与基础系统验收

- [ ] `sdkconfig` flash size 修正为 4MB,构建日志显示目标为 ESP32-C3 且 flash size 不再是 2MB。
- [ ] 建立 `board_pins.h` 或等价 board 层,集中定义硬件文档中的全部引脚:LCD SCLK=4/MOSI=6/DC=7/RST=8/CS=10/BLK=5;TP SDA=2/SCL=3/INT=0/RST=1;BOOT=9。
- [ ] 固件启动后串口打印版本、reset reason、free heap、minimum free heap、largest free block、Wi-Fi 配置状态。
- [ ] BOOT 键短按可触发一个可见/可记录动作(建议:打开/关闭 Control Center 或进入重新配网确认),长按 3 秒进入/清空配网模式。若 BOOT 键与下载模式冲突,实现需避开上电按住场景。
- [ ] 看门狗未在 UI 滑动、配网、NTP、HA 探测期间误触发;连续空闲 10 分钟不重启。

### 2. 显示与 LVGL 验收

- [ ] ST7789 240x320 竖屏点亮,颜色顺序正确(RGB565 红绿蓝测试块不串色),方向正确(顶部热区在屏幕物理顶部)。
- [ ] 背光 GPIO5 由 PWM 控制,可从 10% 到 100% 平滑调整;0% 不作为首版选项,避免误以为死机。
- [ ] LVGL 版本锁定为 8.3.11,启动日志或构建配置可确认版本。
- [ ] 显示 buffer 使用局部 DMA 双缓冲,初始建议 20 行高;验收记录实际 buffer 行数和占用字节数。禁止双全屏 framebuffer。
- [ ] `lv_disp_drv_t.flush_cb` 正确调用 `esp_lcd_panel_draw_bitmap()`,连续滑动 30 秒无撕裂、花屏、错位或 flush 卡死。
- [ ] 使用工单 01 的深色 Frosted Panel 基础样式:背景 `#121214`,卡片 `#1C1C1E`,1px 微亮边框,无实时 blur。
- [ ] 字体链路可用:中文基础字体 C array 能显示“网络 未连接 后端离线 控制中心 亮度 配网”等骨架文案;大号数字字体能显示时间占位符。

### 3. 触摸与手势验收

- [ ] CST816D I2C 初始化成功,使用新版 `driver/i2c_master.h`;复位脚和中断脚按硬件文档工作。
- [ ] 单点点击在四角和中心可被 LVGL 接收,坐标映射与屏幕方向一致。
- [ ] 左右滑动能切换三张 `lv_tileview` 卡片,不会误触发点击按钮;从卡片1滑到卡片3再滑回卡片1至少 20 次无卡死。
- [ ] 顶部 16-24px 热区下拉能打开 Control Center;非顶部区域纵向滑动不应误开控制中心。
- [ ] Control Center 打开时,背景卡片不响应点击;关闭后返回原卡片和原滚动位置。
- [ ] 触摸中断/轮询策略不会让 CPU 空转:空闲时触摸任务无明显高占用,串口日志不刷屏。

### 4. Card Shell 与 Control Center 验收

- [ ] 三张 Card 均可见且顺序固定:卡片1=时钟/天气/日历占位,卡片2=电脑性能/快捷占位,卡片3=智能家居占位。
- [ ] 页面指示点正确显示当前卡片位置,滑动完成后状态更新。
- [ ] 每张占位卡都遵守 240x320 布局约束:顶部安全区、主内容不越界、按钮/占位触摸目标不小于 36x36px。
- [ ] Control Center 包含且仅包含首版控件:亮度滑条、Wi-Fi SSID/IP/RSSI 或未连接状态、HA endpoint/在线离线状态、重新配网入口。
- [ ] Control Center 展开/收起动画目标 25-30 FPS;若真机低于目标,允许减少透明度/阴影/动画时长,但不能牺牲触摸响应。
- [ ] HA Host 未运行时显示 Offline Backend State,文案明确为“后端离线/HA 不可达”,不显示卡片数据成功态。

### 5. Wi-Fi 与 Provisioning Portal 验收

- [ ] 首次无 Wi-Fi 配置时自动进入 SoftAP 配网模式,屏幕显示 AP 名称、IP 和简短状态。
- [ ] 手机连接 SoftAP 后能打开 Provisioning Portal,填写 SSID、密码、可选 HA endpoint、可选 token。页面不回显明文 token。
- [ ] 提交后配置写入 NVS;重启后自动尝试连接 STA,不会再次强制配网。
- [ ] Wi-Fi 连接成功后屏幕显示本机 IP、RSSI 或信号等级。
- [ ] Wi-Fi 密码错误/连接失败时,设备能回到可恢复状态:屏幕显示失败原因概要,并能重新进入配网。
- [ ] Control Center 的重新配网入口可清除或覆盖 Wi-Fi/HA 配置,但需要明确确认动作,避免误触。
- [ ] 配网 HTTP 处理不阻塞 LVGL 动画和触摸超过 500ms 体感阈值。

### 6. 时间与后端探测验收

- [ ] STA 联网后通过 SNTP 对时;对时成功后卡片1占位时钟显示真实本地时间。
- [ ] 未联网或 NTP 失败时,时钟占位显示“未校时”或等价状态,不显示伪准确时间。
- [ ] HA endpoint 已配置时,骨架使用工单 04 的 REST-only 思路做轻量探测(建议 `GET /api/` 或单个配置实体测试);401/404/TLS/连接超时要区分日志,UI 只显示可理解的在线/离线/认证失败概要。
- [ ] HA endpoint 未配置时,UI 显示“未配置 HA”,而不是错误。
- [ ] HA Host 关机/容器停止时,ESP32 在超时后进入 Offline Backend State;HA 恢复后能自动回到在线状态或在下一次刷新恢复。
- [ ] 后端探测网络任务不得在 LVGL 回调中执行,也不得阻塞滑动/触摸。

### 7. 内存、性能和稳定性基线

工单 09 完成时必须记录这些数值,作为卡片1/2/3实现前的基线:

- [ ] 启动进入三卡片壳后:`free_heap`, `minimum_free_heap`, `largest_free_block`。
- [ ] Wi-Fi STA 已连接后同一组三个 heap 指标。
- [ ] 打开 Control Center 并拖动亮度滑条 10 秒后的 minimum free heap。
- [ ] 连续左右滑动 60 秒后的 minimum free heap 和 largest free block,无持续下降趋势。
- [ ] HA endpoint 配置但 HA Host 离线时,后台探测 5 分钟内无 heap 持续下降。
- [ ] 目标帧率:滑动/控制中心动画体感达到 25-30 FPS;如果低于目标,记录原因和降级项。
- [ ] 启动后静置 30 分钟无重启、无明显内存泄漏、无任务 watchdog。

### 8. 工单 09 完成定义

工单 09 只有在以下条件都满足时才能关闭:

- [ ] 上述 1-7 节所有必须项已勾选,任何未完成项都有明确豁免理由和后续工单。
- [ ] 真机串口日志保存一次完整启动到联网/离线探测的片段。
- [ ] 至少拍摄或记录三类现象:三卡片滑动、Control Center 下拉、Provisioning Portal 成功保存配置。
- [ ] 记录实际 flash 占用、RAM 基线和 LVGL buffer 行数。
- [ ] 确认三张业务卡片仍为占位/空数据安全态,没有把模拟数据误当真实功能。
