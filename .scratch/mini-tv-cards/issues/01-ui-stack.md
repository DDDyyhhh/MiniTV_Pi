## Answer

### 结论

采用用户提出的方向,并做两处工程化收紧:

1. LVGL 版本锁定为 **LVGL 8.3.11**,不是浮动的 8.3 或 9.x。理由:LVGL 8.3 已有 `lv_tileview`、display partial/double buffering、C array 字体和成熟控件;Espressif 的 `esp_lvgl_port` 支持 LVGL 8/9,但默认可能解析到最新 9.x,所以实现时必须在 `idf_component.yml` 明确锁定 `lvgl/lvgl: "8.3.11"`,并验证 `esp_lvgl_port` 版本兼容 LVGL 8。LVGL 9.x 可跑,但对本项目小屏无 PSRAM目标没有足够收益,反而增加 API/示例迁移不确定性。
2. “双缓冲”定义为 **局部 DMA 双缓冲**,绝不是双全屏 framebuffer。240x320 RGB565 单全屏约 150 KiB,双全屏约 300 KiB,会挤爆 ESP32-C3 无 PSRAM 的 Wi-Fi、LVGL heap、任务栈和 HTTP 缓冲预算。实现目标为 20-32 行高的 RGB565 DMA 双 buffer:
   - 20 行:`240 * 20 * 2 * 2 = 19200 B`(约 18.75 KiB)
   - 32 行:`240 * 32 * 2 * 2 = 30720 B`(约 30 KiB)
   初版建议从 20 行开始,真机帧率/heap 允许再调到 32 行。

### 技术栈

- 固件保持 ESP-IDF v6.0.2 + C + FreeRTOS。
- UI 使用 LVGL 8.3.11。
- 屏幕链路:ESP-IDF `esp_lcd` + ST7789 panel + SPI DMA + `lv_disp_drv_t.flush_cb` 调 `esp_lcd_panel_draw_bitmap()`。
- 色彩格式:RGB565,优先保持 `LV_COLOR_DEPTH=16`。
- 刷新模型:partial render + DMA 双缓冲;禁止全屏双 framebuffer。
- 触摸链路:CST816D 通过 I2C/INT 驱动读坐标/手势,接入 LVGL indev。若 `esp_lcd_touch_cst816s` 与 CST816D 寄存器/手势兼容,优先复用并包一层 board adapter;不兼容则写最小 CST816D 驱动。
- LVGL 任务:单独 LVGL task 按固定周期调用 `lv_timer_handler()`;网络/HA/HTTP 不得运行在 LVGL 回调内。

### 交互容器

- 三张主卡片使用 `lv_tileview`:横向三个 tile,顺序固定为卡片1(时钟/天气/日历)、卡片2(电脑性能/快捷)、卡片3(智能家居)。
- 页面切换:左右滑动,带页面指示点。首版只允许横向主轴滑动,卡片内部需要滚动时必须避免与主滑动冲突。
- 顶部下拉手势:作为全局控制中心入口。实现时在根层或活动 screen 监听顶部热区的下滑手势;控制中心以 overlay 层出现,覆盖当前 tile,关闭后返回原 tile。
- 控制中心首版内容固定:背光 PWM 滑条、Wi-Fi 状态/IP、重新配网入口。是否增加二级页留给工单 05 骨架验收。

### 视觉系统

采用 **Apple Fluent 深色磨砂卡片风**,但按 ESP32-C3 能力做静态化:

- 背景底色:`#121214`。
- 主卡片/面板底色:`#1C1C1E`,可用 LVGL opacity 表现半透明感,但不做实时高斯模糊。
- 边框:1px 微亮边框,建议 `#3A3A3C` 或同色系低透明白。
- 文字主色:`#F5F5F7`;次级文字:`#A1A1A6`;弱提示:`#6E6E73`。
- 强调色:首版使用 Apple 蓝 `#0A84FF`;警告/错误可用 `#FF453A`;成功/开启态可用 `#30D158`。
- 圆角:主卡片 12-16px;小控件/开关 8-12px。由于项目偏工具型,避免过度圆角和厚重装饰。
- 阴影:不用大半径动态阴影。必要时用 1-2 层低透明黑色偏移矩形/边框模拟层次,不得明显拖慢滑动。
- 毛玻璃:命名为“Frosted Panel”,用静态深色、透明度、边框和轻微渐变表达;明确不使用实时 blur。
- 动效:横向 tile 切换和控制中心展开以流畅优先,目标 25-30 FPS;翻页时钟动效可降级为分段/遮罩动画,不能牺牲触摸响应。

### 字体与字符子集

采用中文字符裁剪(Font Subsetting),以 C 数组静态编译进固件:

- 中文 UI 字体目标:约 300-500 个常用字,覆盖时间、星期、气象、日历/节假日、Wi-Fi/控制中心、智能家居房间和状态词。
- 体积目标:中文字体数组总量控制在 **50 KiB 内**。这是可行但依赖字号/bpp:16px 1bpp/2bpp 较稳;20px 2bpp 接近或可能超过;24px 或 4bpp 不纳入中文通用字体预算。
- 建议拆分:
  - `font_cn_16`:中文正文/标签,16px,1bpp 或 2bpp,300-500 字。
  - `font_num_large`:大号数字翻页时钟,仅 `0-9:.-/` 和少量拉丁符号,可用 48-72px,不包含中文。
  - `font_icon` 或 LVGL symbol:仅必要图标/符号,优先用 LVGL 内置 symbol 或小位图。
- 生成方式:使用 LVGL font converter,按明确字符清单生成 C array,通过 `LV_FONT_DECLARE(...)` 引用。字符清单随卡片 06/07/08 的最终文案补全;工单 09 先放基础字符集,后续只增量扩充。
- 禁止全量 GB2312/中文字库。

### 布局约束

- 屏幕按竖屏 240x320 设计。
- 根安全区:顶部预留 16-24px 给状态/下拉手势;主内容宽度建议 216-224px,左右边距 8-12px。
- 单卡片最多 3 个纵向信息区,避免在 240px 宽屏塞过多文字。
- 所有按钮/Entity Tile 的触摸目标建议不小于 44x44px;若控件密集,最小不低于 36x36px。
- 文案必须短,避免自动换行造成布局抖动。长实体名在 ESP32 侧使用配置别名或截断,不直接展示 HA 原始 `friendly_name`。
